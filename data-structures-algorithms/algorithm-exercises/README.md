# Algorithm Exercises

A collection of algorithm implementation exercises from coursework modules.

## Overview

This directory contains various algorithm exercises completed as part of the algorithms and data structures coursework. Each module focuses on different algorithmic concepts and problem-solving techniques.

## Files

- `algorithms_module2.py` - Module 2 algorithm exercises
- `algorithms_ct3.py` - Critical Thinking 3 algorithm problems
- `algorithms_module6.py` - Module 6 algorithm implementations
- `algorithms_module7.py` - Module 7 algorithm exercises
- `algorithms_module8.py` - Module 8 algorithm problems

## Topics Covered

These exercises demonstrate various algorithmic concepts including:
- Algorithm design and analysis
- Problem-solving strategies
- Code optimization
- Complexity analysis
- Data structure manipulation

## Usage

Each file can be run independently:

```bash
python algorithms_module2.py
python algorithms_ct3.py
python algorithms_module6.py
python algorithms_module7.py
python algorithms_module8.py
```
